# Matken Connected Conduit Brand System

Status: prototype brand direction for client review. Trademark clearance,
business-owner approval, printer/vendor proofs, and production signoff are
still required.

## Core idea

The mark turns a structural capital `M` into connected electrical conduit:
sturdy outside stems, a central 45-degree chevron, and one red square
connection node. The system is intended to feel capable across electrical,
solar, and construction work without using a generic lightning-bolt symbol.

The wordmark is set in the bundled Manrope ExtraBold face. The optional
descriptor is:

`ELECTRICAL · SOLAR · CONSTRUCTION`

## Palette

- Matken Navy: `#061831`
- Connection Red: `#CF2630`
- White: `#FFFFFF`
- Black-only production mark: `#101820`
- UI yellow: `#FFC42E` — reserved for website calls to action and highlights;
  it is not part of the primary logo.

## Usage rules

- Keep clear space around the full logo equal to the red node’s width.
- Do not use the horizontal lockup below 160 CSS pixels; use the compact mark.
- Keep the red node red in full-color and reversed applications.
- Do not stretch, skew, outline, add shadows, rearrange the letters, rotate the
  mark, or place it on a low-contrast image.
- Use the reversed artwork on Matken Navy. Use the navy/red artwork on white or
  very light neutral backgrounds.
- Use the monochrome asset when a vendor can reproduce only one ink.
- Vendor files must be proofed at real size before vehicles, signage,
  embroidery, or hard-hat decals are ordered.

## Approval boundary

These files are a complete prototype system, not evidence of trademark
availability or owner approval. Before production, Matken must approve the mark,
wordmark spelling, descriptor, colors, public phone use, and every physical
application. A qualified trademark professional should clear the final mark in
the intended jurisdictions and service classes.
